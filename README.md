# shivamrandive747.github.io

Personal academic website of Shivam Randive, live at <https://shivamrandive747.github.io>.

Plain HTML and CSS with no build step, served by GitHub Pages.

- `index.html`: page content
- `style.css`: styles (light and dark mode follow the visitor's system setting)
- `assets/`: CV PDF and figures
- `.nojekyll`: tells GitHub Pages to serve the files as they are

To update the CV, replace `assets/Shivam_Randive_CV.pdf` and push.
